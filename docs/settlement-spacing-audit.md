# Сверка отступов страницы посёлка — 26 ноября 2026

Проверена `/poselki/troitskaya-sloboda`. Изменения общего шаблона дополнительно проверены на всех семи страницах посёлков. Работа локальная, публикация не выполнялась.

## Источники

Файл Figma `nsStsZbQXuGUeyC447G4xO`:

| Режим | Узел | Применение |
| --- | --- | --- |
| Широкий десктоп | `4118:27040` | ширина окна >1280 px, композиция 1920 |
| Компактный десктоп | `4126:24171` | только 1024–1280 px, масштаб через общие токены |
| Планшет | `4126:24415` | 768–1023 px |
| Мобильный | `4126:24765` | <768 px |

Макет компактного десктопа не применяется при ширине окна 1440 px. Проверка ширины выполнялась по `window.innerWidth`; у браузера оставался системный отступ полосы прокрутки 15 px, поэтому доступная ширина содержимого немного меньше ширины окна.

## Исправлено

- Описание посёлка: максимальная ширина 884 единицы макета, отступ до строки об отсутствии взносов — 20 px.
- Слот карты: пропорции 1840×900, 1360×700, 728×900 и 335×700 для четырёх режимов. Содержимое карты оставлено временным по согласованному решению.
- Видео: отступ от описания до превью 32 единицы на десктопе и 32 px на мобильном; ширина превью и внутренние отступы приведены к соответствующим фреймам. На планшете верхний и нижний отступы — 72 px.
- На планшете заголовки используют существующий общий масштаб для вертикальной композиции, с пределом 72 px.
- Мобильная галерея: промежуток между управляющими кнопками — 8 px. Мобильный генплан: от заголовка до схемы — 64 px.
- Карточки просмотра: внутренний промежуток до кнопки — 32 единицы на десктопе и 24 px на мобильном.
- Карточки оплаты на планшете и мобильном: промежутки по 64 единицы, высота определяется содержимым. У первой карточки сохранено место, соответствующее верхней кнопке остальных карточек.
- Форма презентации: восстановлен общий промежуток между вводным текстом и формой (64 единицы, мобильный — 32 px), планшетные внутренние отступы 32×24 px. После блока используется общий межсекционный отступ.

## Проверки

- 70 сочетаний: семь посёлков на ширинах 375, 767, 768, 1023, 1024, 1280, 1281, 1440, 1512 и 1920 CSS px.
- Горизонтального переполнения страницы и формы не обнаружено. Сохранены обе карточки просмотра, четыре способа оплаты и переходы из рекомендаций.
- Фотографии карточек просмотра квадратные на всех проверенных ширинах, согласно правилам проекта. Это согласованное отличие от отдельных фреймов Figma.
- На каждом посёлке при 375 и 1512 px проверены валидация формы презентации, тестовый успех с общим окном «Спасибо!», повторная отправка после закрытия и имитация ошибки. Всего 14 сценариев с четырьмя состояниями.
- Визуально проверены исправленные блоки на мобильном, планшете и широком десктопе.
- `npm run build` прошёл, включая TypeScript и `check:responsive` (47 CSS-файлов). `git diff --check` прошёл.
