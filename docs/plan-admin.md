# Управление генпланами

Адрес: `/admin/genplany`. Выберите посёлок и генплан. Нажмите участок на фото или найдите его по номеру в списке справа. Измените номер, площадь в сотках, полную стоимость в рублях, статус, очередь и признак «В сумму сертификата», затем нажмите «Сохранить». Изменения появляются на публичной странице при следующем открытии или перезагрузке.

Контуры и фотография генплана фиксированы. В админке редактируются данные существующих участков; инструменты рисования, изменения контура и замены фото убраны по запросу Екатерины от 26 ноября 2026 года. ID участка сохраняется при изменении его номера.

В настройках можно добавлять и переименовывать очереди. Очередь с назначенными участками удалить нельзя: сначала перенесите их в другую очередь. Назначение очереди и коммерческий статус — независимые поля; признак сертификата также хранится отдельно. На публичной схеме сертификатный фильтр показывает только участки в продаже с этим признаком.

Импорт JSON проверяет участки, координаты, ID, статусы, очереди и принадлежность экспорта текущему посёлку. Экспорт сохраняет текущую версию редактора, включая несохранённые правки.

## Доступ и хранение

Админка использует общие именные учётные записи, роли и одобрение заявок. Владелец входит с логином `admin` и существующим паролем `PLAN_ADMIN_PASSWORD` (или `ADMIN_OWNER_PASSWORD`, если задан). Сохранять генпланы могут администратор и менеджер участков; наблюдатель имеет доступ только к просмотру. Подробности: [Управление сайтом](site-admin.md).

Сохранённые данные находятся в `.data/plans/<slug>.json`. Каталог исключён из Git и не является публичной папкой. Для другого места хранения задайте `PLAN_DATA_DIR`. Сохранение атомарное; номер версии защищает от перезаписи старой копией из другой вкладки. Перед переносом сервера сохраните этот каталог или экспортируйте JSON. Файловое хранилище рассчитано на один постоянно работающий экземпляр Next.js с доступным для записи диском; при размещении нужен постоянный том. Для нескольких экземпляров сервера слой `lib/plan-store.ts` следует заменить общим хранилищем с атомарной проверкой версии.

Статический предпросмотр GitHub Pages собирается отдельно: он показывает исходные генпланы и сообщение о доступности админки в серверной версии. Сохранение и серверные пароли в статическую сборку не попадают. Эта работа не включает публикацию сайта или страницы Троицкой Слободы.

## Проверки

`npm run test:plans` проверяет валидность исходных данных, сохранение на диск, конфликт параллельных версий и отклонение некорректных изменений. `npm run build` включает проверку адаптивных правил и TypeScript. В браузере проверены вход, защита записи, сохранение и повторная загрузка, публичное обновление, редактирование данных участка, отмена правок, выбор всех посёлков, фильтры и атрибуция выбранного участка.

Высота публичного генплана подстраивается под окно с учётом шапки и отступов, минимум — 540 CSS-пикселей. На низком окне нижний предел может потребовать прокрутку страницы. Кнопка полноэкранного режима удалена по запросу Екатерины.
