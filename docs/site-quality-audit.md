# Проверка компонентов, SEO и ресурсов — 27.11.2026

Проверено текущее локальное состояние проекта, включая незакоммиченные страницы и админку. Изменения не отправлялись в GitHub. Троицкая Слобода остаётся локальной разработкой и не включена в sitemap.

## Изменения

- Страница согласия на обработку персональных данных переведена на общий `LegalDocument`. Удалён её отдельный файл CSS; согласованные ширина заголовка, интервалы, тексты, ссылки и ключи CMS сохранены через явный вариант компонента.
- Повтор обновления SEO из CMS в 13 файлах заменён общей `localizePageMetadata`. Она синхронно обновляет title/description для поиска, Open Graph и Twitter.
- Общая `createPageMetadata` задаёт адрес текущей страницы даже без индивидуальной фотографии, общее название сайта, изображение по умолчанию и Twitter-карточку. Страницы посёлков используют этот же контракт со своей фотографией, заголовком и описанием вместо наследования превью главной.
- Sitemap дополнен шестью существующими страницами посёлков. В основной конфигурации — 20 уникальных адресов. Превью сохраняет `noindex`, пустой sitemap и отсутствие canonical; основная индексация требует `SITE_URL`.
- Добавлен `ResponsiveImage`: один элемент `img` с общими `srcset` и `sizes`, без дополнительной обёртки. Семь тяжёлых фотографий получили версии 640/1280/1920 px. Исходники, пропорции, CSS и кадрирование сохранены. При замене изображения через CMS используется загруженный файл; старый набор `srcset` к нему не применяется.
- Удалены шесть одинаковых фотографий проекта «Уютный», две одинаковые SVG радиокнопок и неиспользуемая карта офиса PNG. Ссылки на фотографии и радиокнопки переведены на существующие общие файлы. Суммарно удалено около 1,6 МБ исходных ресурсов. Проверено отсутствие ссылки на удалённую карту в сохранённых локальных значениях CMS.
- Удалены неиспользуемые импорты и переменная открытия старой кнопки просмотра посёлка.
- Добавлены `npm run test:seo` и воспроизводимая генерация файлов `npm run images:responsive` (Node.js >=22; используется Sharp из зависимости Next.js).

Формы, атрибуция заявок, генпланы, карты, карточки и сценарии каруселей продолжают использовать существующие общие компоненты. Разные композиции страниц не объединялись по случайному совпадению отдельных CSS-свойств. Файлы с динамическими путями и зарегистрированные в CMS изображения не удалялись только на основании отсутствия прямого импорта. Повторяющиеся служебные копии каруселей сохранены.

## Проверки

- `npm run build`: обычная серверная сборка прошла.
- Сборка `PAGES_PREVIEW=1` с базовым путём `/udachny-poselok` прошла. Проверены 21 экспортированная публичная страница, `noindex`, отсутствие canonical и 478 путей к ресурсам: отсутствующих файлов нет.
- `tsc --noEmit --noUnusedLocals --noUnusedParameters`: проверка типов и неиспользуемых импортов/локальных переменных.
- `npm run check:responsive`: 47 файлов CSS.
- `npm run test:plans`, `npm run test:admin`, `npm run test:seo`: по три успешных теста, всего девять. SEO-тесты охватывают основной домен, CMS, превью с подпапкой и отсутствие настроенного домена.
- Локальный Chrome: 21 публичная страница × 10 ширин = 210 проверок. Ширины по `window.innerWidth`: 375, 767, 768, 1023, 1024, 1280, 1281, 1440, 1512, 1920 px. Все страницы ответили 200; по одному H1, title совпадает с OG/Twitter title, горизонтального переполнения и ошибок JavaScript нет. Количество элементов во всех проверенных списках сохраняется между ширинами.
- Сопоставление до/после: 58 состояний, включая обе юридические страницы на всех десяти ширинах. Совпали высоты основной области, размеры и положение H1, текст юридических документов и отсутствие переполнения.
- Проверены 435 уникальных путей изображений/ресурсов в браузерном обходе: HTTP-ошибок нет. Открытие четырёх галерей домов и загрузка всех их фотографий проверены отдельно на мобильном и десктопе.
- 24 проверки встроенных форм на 12 страницах при 375 и 1512 px: валидация, успешная отправка, повторная отправка после закрытия общего окна «Спасибо!», имитация ошибки. Заявки тестовые. Отдельно проверен квиз главной на мобильном и десктопе.
- Визуально просмотрены контрольные скриншоты юридической страницы и первых экранов с адаптивными фотографиями. Новый файл Figma в этой задаче не задан; соответствие исходному макету заново не удостоверялось. Сохранение геометрии не заменяет такую сверку.
