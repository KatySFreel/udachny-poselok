# Удачный посёлок

Главная страница на Next.js. Для локального предпросмотра нужен Node.js 22 и команды `npm ci`, `npm run dev`.

Статическая версия для GitHub Pages:

```sh
PAGES_PREVIEW=1 NEXT_PUBLIC_BASE_PATH=/udachny-poselok PREVIEW_URL=https://OWNER.github.io npm run build
```

Готовые файлы будут в `out/`. Подставьте имя опубликованного репозитория в `NEXT_PUBLIC_BASE_PATH`. На статическом предпросмотре формы имитируют отправку, а поисковым роботам передаётся `noindex`.

Для основного сайта задайте `SITE_URL` с финальным адресом и используйте обычную серверную сборку `npm run build`. Канонический адрес и карта сайта будут строиться из `SITE_URL`. Квиз использует `QUIZ_WEBHOOK_URL`, если переменная задана на сервере. Перед индексацией нужно завершить внутренние страницы и подключить реальную отправку форм.
